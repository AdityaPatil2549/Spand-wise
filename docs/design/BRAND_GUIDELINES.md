# Brand Guidelines
## SpendWise — Student Expense Tracker
**Version 1.0 | July 2026**

---

## 1. Brand Identity Overview

SpendWise is the trusted financial companion for students. Our brand communicates:
- **Intelligence** without arrogance
- **Warmth** without being childish  
- **Confidence** without being intimidating
- **Simplicity** without being boring

We are **not** a bank. We are not a corporate financial tool. We are the smart friend who happens to be really good with money.

## 3. Logo System

### 3.1 Primary Logo
The SpendWise logo consists of:
1. **The Icon Mark:** A stylized rupee coin with an upward trend spark (₹ + ✦)
2. **The Wordmark:** "SpendWise" in Plus Jakarta Sans ExtraBold

### 3.2 Logo Variations

| Variant | Usage |
|---|---|
| Full Horizontal (icon + wordmark) | Primary — headers, marketing |
| Icon Only | App icon, favicon, small spaces |
| Wordmark Only | Where icon would be too small |
| Reversed (white on color) | Dark backgrounds, hero sections |

### 3.3 Logo Colors

| Background | Logo Color |
|---|---|
| White / Light | Primary Purple (#7c3aed) |
| Dark / Black | White (#ffffff) |
| Brand gradient | White (#ffffff) |
| Colored | White (#ffffff) or Black |

### 3.4 Logo Clear Space
Minimum clear space = height of the "S" in SpendWise on all four sides. Never place other elements, text, or images within this clear space.

### 3.5 Logo Minimum Sizes
- Full horizontal: minimum 120px width
- Icon only: minimum 24px × 24px
- Wordmark only: minimum 80px width

### 3.6 Logo Don'ts
- ❌ Don't stretch or distort
- ❌ Don't rotate
- ❌ Don't add drop shadows
- ❌ Don't change colors (only approved color variants)
- ❌ Don't place on busy backgrounds without sufficient contrast
- ❌ Don't recreate or redraw the logo

## 5. Typography

### 5.1 Primary Font: Plus Jakarta Sans
**Why:** Geometric, modern, extremely legible on screens. Has personality without being playful. Conveys the professionalism of finance with the approachability of a student app.

**Weights Used:**
- Regular (400) — Body text, descriptions
- Medium (500) — UI labels, secondary headings
- SemiBold (600) — Section headers, emphasis
- Bold (700) — Page titles, category names
- ExtraBold (800) — Hero numbers, display text

### 5.2 Monospace Font: JetBrains Mono
**Why:** Financial amounts need to be scannable in columns. Monospaced fonts ensure digits align perfectly. JetBrains Mono is beautiful and legible.

**Usage:** All monetary amounts (₹1,250), dates in tables, data displays.

### 5.3 Type Scale Summary

| Use Case | Family | Weight | Size |
|---|---|---|---|
| Remaining Budget (Hero) | JetBrains Mono | 800 | 40–56px |
| Page Titles | Plus Jakarta Sans | 700 | 24px |
| Section Headers | Plus Jakarta Sans | 600 | 18px |
| Expense Amounts | JetBrains Mono | 600 | 16px |
| Category Labels | Plus Jakarta Sans | 500 | 14px |
| Body / Notes | Plus Jakarta Sans | 400 | 15px |
| Timestamps | Plus Jakarta Sans | 400 | 12px |
| Buttons | Plus Jakarta Sans | 600 | 15px |

### 5.4 Typography Rules
- **Never** use more than 2 font families in one screen
- **Never** use font sizes below 12px
- **Always** use JetBrains Mono for all currency amounts — never Plus Jakarta Sans for numbers
- Line length should not exceed 65 characters on desktop for comfortable reading
- Headlines should use tight letter spacing (–0.02em)

## 6. Imagery & Illustration Style

### 6.1 Photography (Marketing Only)
- Authentic student life: real campuses, real moments, real diversity
- Warm, slightly desaturated tones with purple accent overlays
- Never stock photo "business" imagery
- Show students in natural settings: studying, in canteens, with friends

### 6.2 Illustration Style
- Flat vector illustrations with gradient fills (using brand purple family)
- Simple geometric shapes — not detailed or realistic
- Characters: simplified, diverse skin tones, gender-neutral when possible
- Used for: empty states, onboarding screens, error pages

### 6.3 Icons
- Lucide React icons (stroke-based, 1.5px stroke width, rounded caps/joins)
- Always sized per the icon scale in DESIGN.md
- Category icons use emoji as primary display; Lucide as fallback

### 6.4 Charts & Data Visualization
- Donut charts for category breakdown (not pie — center shows total)
- Line charts for trends (smooth curves, no sharp angles)
- Bar charts for comparisons (rounded bar caps)
- Colors: always use category color tokens, not arbitrary colors
- Always include accessible labels (not color-only differentiation)

## 7. Voice & Tone

### 7.1 Brand Voice Characteristics

| Characteristic | What It Means | Example |
|---|---|---|
| **Clear** | Simple language, no jargon | "You've spent ₹4,500 on food" not "Food expenditure: ₹4,500" |
| **Encouraging** | Supportive, not judgmental | "Great job! You're within budget." not "Warning: budget used" |
| **Honest** | Tells the truth simply | "Budget exceeded" not "Optimal spending threshold breached" |
| **Human** | Written by a friend, not a bank | "Where did your money go this month?" not "Monthly expenditure report" |
| **Brief** | Respects the student's time | Every word earns its place |

### 7.2 Tone Variations by Context

**Empty States:**
- Warm and inviting: "Your expense list is empty. Add your first expense with the + button!"
- Never cold: "No records found."

**Error Messages:**
- Helpful and specific: "We couldn't save this expense. Check your connection and try again."
- Never cryptic: "Error code 503."

**Success States:**
- Celebratory but not over-the-top: "Expense added! ₹150 less from your budget."
- Never clinical: "Transaction recorded."

**Budget Warnings:**
- Gentle but clear: "Heads up — you've used 80% of your budget. ₹1,600 remaining."
- Never alarming: "CRITICAL: Budget threshold exceeded!"

### 7.3 Writing Don'ts
- ❌ Financial jargon (expenditure, transaction, threshold)
- ❌ All caps for warnings
- ❌ Passive voice ("expense was deleted" → "We deleted that expense")
- ❌ Vague error messages
- ❌ Long sentences in UI copy (keep UI text under 80 characters)

## 10. Motion Brand Standards

SpendWise moves with intention. Our motion philosophy:

1. **Responsive:** UI responds to every interaction (no "dead" moments)
2. **Natural:** Movements follow physical metaphors (slides, bounces feel real)
3. **Fast:** We never waste the user's time with long animations
4. **Purposeful:** Animation communicates state changes, not decoration

**Brand Motion Signature:**
- Entry animations: slide up + fade in (bottom-to-top, 250ms, ease-decelerate)
- Exit animations: fade out (150ms, ease-accelerate)
- Emphasis: subtle scale spring (1.0 → 1.02 → 1.0, 300ms, spring easing)
- Number changes: count-up animation (0 → value, 600ms, ease-smooth)
