# UX Copy Guidelines
## SpendWise — Student Expense Tracker

UX copy is every piece of text a user reads inside the app — buttons, labels, toasts, instructions, and empty states. Great copy reduces confusion, builds trust, and adds personality.

---

## 1. Voice and Tone

### Brand Voice (Consistent)
SpendWise is a **supportive financial coach**, not a bank or a calculator.

| Attribute | What it means in copy |
|:---|:---|
| **Friendly** | Writes like a smart friend, not a corporation |
| **Encouraging** | Celebrates progress; never guilts or shames |
| **Clear** | One idea per sentence. No jargon. |
| **Concise** | Mobile copy: maximum 10 words per sentence |
| **Honest** | Never oversells; never hides bad news |

### Tone Shifts (Situational)
| Situation | Tone |
|:---|:---|
| Onboarding | Excited and welcoming |
| Under-budget success | Celebratory, warm |
| Budget warning | Firm but kind, not alarming |
| Budget exceeded | Direct and matter-of-fact, not panicky |
| Errors | Calm, apologetic, action-oriented |
| Empty states | Encouraging, opportunity-framed |

---

## 2. Standard Copy Rules

### Dos
- ✅ Use contractions: "You've", "It's", "Don't"
- ✅ Use second person ("You", "Your")
- ✅ Use active voice: "Add your first expense" not "An expense should be added"
- ✅ Lead with the action: "Download PDF" not "Click here to download your PDF"
- ✅ Use numbers: "3 expenses today" not "Several expenses today"

### Don'ts
- ❌ Use financial jargon: "liquidity", "allocation", "expenditure"
- ❌ Use passive voice: "The expense was deleted" → "Expense deleted"
- ❌ Use ALL CAPS for emphasis (use bold or color instead)
- ❌ Use exclamation marks in error states
- ❌ Use "please" in buttons (wastes space)

## 3. Standard Copy Bank

### Buttons
| Action | Label |
|:---|:---|
| Add expense | `+ Add Expense` |
| Save changes | `Save Changes` |
| Delete expense | `Delete` |
| Undo deletion | `UNDO` |
| Download PDF | `Download PDF` |
| Export CSV | `Export CSV` |
| Sign in (Google) | `Continue with Google` |
| Sign out | `Sign Out` |
| Delete account | `Delete My Account` |

### Toasts
| Event | Message |
|:---|:---|
| Expense added | `₹{amount} added to {category}` |
| Expense updated | `Expense updated` |
| Expense deleted | `Expense deleted · UNDO` |
| Report downloading | `Generating your report...` |
| Report ready | `Report downloaded!` |
| Save failed (network) | `Couldn't save. Check your connection.` |
| Generic error | `Something went wrong. Try again.` |

### Dashboard Greetings (Time-Based)
| Time | Greeting |
|:---|:---|
| 5 AM – 12 PM | `Good morning, {name} ☀️` |
| 12 PM – 5 PM | `Good afternoon, {name} 👋` |
| 5 PM – 9 PM | `Good evening, {name} 🌆` |
| 9 PM – 5 AM | `Hey night owl, {name} 🦉` |

### Budget Status Labels
| State | Label |
|:---|:---|
| < 50% spent | `You're on track` |
| 50–79% spent | `Spending normally` |
| 80–99% spent | `Watch your budget` |
| 100%+ spent | `Budget exceeded` |

## 4. Microcopy Examples

### Onboarding
- **Headline:** "What's your monthly allowance?"
- **Subtext:** "This helps SpendWise tell you when to slow down."
- **Button:** "Let's Start Tracking →"

### Privacy
- **On login screen:** "We never see your transactions. Your data lives in your account."

### Data Deletion
- **Confirmation modal:** "Delete your account?"
- **Body:** "This will permanently delete all your expenses, categories, and budget history. This cannot be undone."
- **Danger button:** "Yes, Delete Everything"
- **Cancel:** "Never Mind"
