# Contributing to Spend-wise

First off, thank you for considering contributing to Spend-wise! It's people like you that make Spend-wise such a great tool for personal finance.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally: `git clone https://github.com/your-username/Spand-wise.git`
3. Install dependencies: `npm install`
4. Copy `.env.example` to `.env.local` and add your Firebase credentials.
5. Start the development server: `npm run dev`

## Branching Strategy
- Create a new branch for your feature or bugfix: `git checkout -b feature/your-feature-name` or `git checkout -b fix/your-bug-name`.
- Keep your commits small and focused.

## Pull Request Process
1. Ensure your code passes all linting standard (`npm run lint`).
2. Update the README.md with details of changes to the interface, if applicable.
3. Submit a PR using the standard Pull Request Template provided in the repository.
4. Wait for code review approval from a core maintainer before merging.

## Code Style
This project uses ESLint and Prettier. Please ensure your editor is configured to format on save, or run the formatter manually before committing.
